## 3. 题目与已经确定的数学认识

### 3.1 原始输入

权威存档：[data/supplied_case.json](../data/supplied_case.json)。

| 时间 t / s | x / m | y / m | z / m |
|---:|---:|---:|---:|
| 0 | 0 | 0 | 0.11 |
| 0.05 | 1.50 | 0.45 | 0.44 |
| 0.10 | 2.96 | 0.86 | 0.74 |

目标是球心第一次向前穿过 `x = 11 m` 时的位置；球门矩形为 `-3.66 < y < 3.66 m`、`0 < z < 2.44 m`。

### 3.2 为什么不能声称已经反演出足球旋转

初始位置被题目给定并作为精确初值，后续两点提供 **6 个标量动态约束**。不能简单把三个位置的九个坐标都当成约束未知动力学的独立信息。

| 待估模型 | 动态未知量 | 当前信息是否足够 |
|---|---:|---|
| 初速度 + 任意有效加速度 | 3 + 3 = 6 | 可以恰好插值，但没有残差自由度 |
| 重力 + 固定阻力，只估初速度 | 3 | 可做受物理约束的最小二乘 |
| 重力 + 未知阻力 + 初速度 | 4 | 形式上可拟合，短窗下仍可能不稳定 |
| 初速度 + 阻力 + 三维旋转，其他常量固定 | 至少 7 | 对 6 个约束欠定 |
| 再独立估计升力比例或环境密度 | 更多 | 不会因为增加未知量而变得可辨识 |

代码的局部敏感性诊断对一个 6×7、带明确参数尺度的矩阵求秩，得到秩 6 和非零零空间方向。它支持局部欠定分析，**不代表对所有未知物理参数进行了精确误差测量**。实际 M2 还让空气密度在先验中变化，因此自由度问题不会更轻。

旋转方向与速度平行的分量在初始时刻不产生马格努斯力；旋转大小和独立升力比例也存在耦合。优化器返回一个数值解，不等于该解在物理上唯一。

## 4. 三个模型怎样工作

### 4.1 M0：恒加速度基线

设 `h = 0.05 s`，`d1 = r(h)-r0`，`d2 = r(2h)-r0`：

\[
\mathbf v_0=\frac{4\mathbf d_1-\mathbf d_2}{2h},\qquad
\mathbf a=\frac{\mathbf d_2-2\mathbf d_1}{h^2}.
\]

再用 `r(t)=r0+v0*t+a*t²/2` 求第一次有效向前交点。该加速度是早期观测窗口上的 **effective acceleration**，不是已证明恒定的真实空气动力。

题目案例得到 `v0=(30.4, 9.4, 6.9) m/s`、`a=(-16, -16, -12) m/s²`。必须排除后续返回的数学根，并统计无实根或预测先落地的情况。

这一模型能恰好通过观测点，但两次差分会放大噪声；插值完美不代表外推可靠。

### 4.2 M1：重力 + 二次阻力

采用 SI 单位：

\[
\dot{\mathbf r}=\mathbf v,\qquad
\dot{\mathbf v}=-g\mathbf e_z-kC_D|\mathbf v|\mathbf v,
\quad k=\frac{\rho A}{2m}.
\]

固定 `Cd=0.25`、`rho=1.225 kg/m³`、无旋转，仅拟合三个初速度分量。因此不能把 `Cd=0.25` 写成根据给定轨迹测出的阻力系数。另有阻力扫描结果用于诊断，并未偷偷替换 M1 的定义。

### 4.3 M2：含旋转的概率空气动力预测

增加简化马格努斯项：

\[
\dot{\mathbf v}=-g\mathbf e_z-kC_D|\mathbf v|\mathbf v
 +k\alpha R(\boldsymbol\omega\times\mathbf v).
\]

这里采用假定的线性升力关系 `Cl = alpha*R*|omega|/|v|`，固定 `alpha=1`。叉积带入旋转轴与速度的夹角效应。**这条升力定律是本项目简化假设，不是从某篇文献抄来的已校准经验式。**

主先验如下，均为敏感性分析假定范围，不是这颗球的实测概率分布：

| 参数 | 主设置 |
|---|---|
| 质量 m | 0.43 kg，代表值 |
| 半径 R | 0.11 m，代表值 |
| 截面积 A | πR² |
| 重力 g | 9.81 m/s² |
| Cd | Uniform[0.12, 0.40] |
| 空气密度 rho | Uniform[1.15, 1.30] kg/m³ |
| 旋转大小 | Uniform[0, 80] rad/s |
| 旋转轴 | 各向同性 |
| 速度先验 | 每分量 [-60, 60] m/s，且初始前向速度为正；在拟合解附近视作常数 |

质量、尺寸与 IFAB 允许范围相符，不等于实测。文献证明足球空气动力会随球型和流动状态变化，**并没有替本项目校准上述先验**。

### 4.4 M2 的推断流程

1. 从先验抽取 `eta=(Cd, rho, omega)`。
2. 在每组 eta 下，对两次位置观测拟合三个初速度分量。
3. 保存最小残差平方和 `S_i` 和位置对初速度的雅可比 `J_i`。
4. 用局部 Laplace 近似积分掉初速度，权重正比于：

\[
w_i\propto\frac{\exp[-S_i/(2\sigma^2)]}
{\sqrt{\det(J_i^TJ_i)}},\qquad
N_{\rm eff}=\frac1{\sum_i w_i^2}.
\]

5. 对观测加假定测量噪声，在给定 eta 的条件下重新拟合初速度并传播，近似条件初态分布。这一步不是再做一次似然更新。
6. 汇总加权交点、事件概率、协方差、分位数和 ESS。

注意：M2 不是把旋转和阻力全部同时拟合成一个“精确解”，也不是随便抽一批轨迹后对所有轨迹等权平均。

### 4.5 数值积分与边界

- 使用已有 NumPy 实现的批量 RK4；当前项目不依赖 SciPy。
- 预测积分步长 0.01 s；合成真值步长 0.0025 s。
- 用三次 Hermite 插值和 36 次二分定位事件，不取离球门最近的离散采样点。
- 球心下降到 `z=R=0.11 m` 时终止自由飞行；没有实现反弹。
- `propagate` 目前默认最长积分时间 2 s。若以后扩展到明显不同的速度或场景，必须复核这个上限；超时状态不应被解释成数学上证明永远不穿门。
- 典型状态包括 `goal_plane`、`ground_before_goal`、`no_forward_crossing`、`numerical_failure`，含义不同，不能混为“数值失败”。

## 6. 合成验证结果及正确的分母

### 6.1 主实验设计

- 1,000 条不同的合成踢球轨迹，四档位置噪声；**不是 4,000 条相互独立的新踢球轨迹**。
- 初速 Uniform[22,35] m/s，方位角 Uniform[-22,22]°，仰角 Uniform[5,18]°；均是测试人群设计，不是真实 FIFA 统计。
- 每个估计器只接收初值、两次早期位置和时间；不能读取真实初速度、旋转、阻力或未来交点。
- 三模型共享每条案例的噪声观测；四档噪声由同一批标准化噪声缩放。
- 共 958 条真值为空中穿门平面，42 条先落地；不能把后者删除后说“全部案例成功”。

原始逐案例记录：[validation_raw.csv](../results/validation_raw.csv)。

### 6.3 对模型优劣的可用结论

M2 在四档测试中共同 RMSE 最低，但优势大小明显变化。5 cm 噪声时与 M1 只差约几毫米，不能仅凭这张表宣称有显著实际优势。分类准确率也不是每个噪声档都由 M2 胜出。

本项目没有支持“最简单的恒加速度模型在原题 0.10 s 条件下整体最好”。应如实写出它对噪声敏感。后面的扩展时长实验则提供了它优于遗漏旋转的 M1 的具体情形。

### 6.4 独立的模型失配实验

另生成 1,000 条轨迹，更改前向模拟的升力饱和和速度相关阻力，预测器仍使用原主模型。sigma=0.01 m 下，M2 共同 RMSE 约 0.308 m，区域覆盖率约 99.5%。

这不等于“任何模型失配都能稳健处理”：这里的饱和升力使轨迹偏转较弱，测试反而容易一些；覆盖率高也意味着区域可能偏保守。只能对这一组明确指定的失配方式作解释。

## 7. 敏感性和仍应优先研究的问题

### 7.1 不确定性分解

中央题目案例中，固定代表性空气动力参数时，测量噪声造成的 y/z 标准差约 0.034/0.033 m；固定观测、仅保留 nuisance 参数分散时约 0.248/0.234 m；合并后约 0.250/0.237 m。

由此可说：**在当前条件假设下，未知空气动力对交点分散的影响大于固定参数下的位置噪声传播。**

“空气动力-only”仍使用 sigma=0.01 m 的似然来给参数加权，不是把测量误差设为零重新反演；这三种条件实验也不是严格可相加的因果方差分解。

### 7.2 先验依赖必须保留

把旋转先验上限从 40 改为 120 rad/s，题目平均 y 从约 3.17 变为 2.98 m，几何穿门概率从约 99.97% 变为 93.02%。这足以说明先验选择不是无关紧要的实现细节。

详见 [prior_sensitivity.csv](../results/prior_sensitivity.csv)。其中另一次 80 rad/s 场景的采样结果与主案例存在蒙特卡洛波动；不要为了表面一致手动改成同一个百分数。

### 7.3 两类蒙特卡洛收敛证据不要混淆

1. **题目中央案例：** N=1,000/5,000/10,000 时，平均 y 约 3.089/3.088/3.083 m；对应概率约 96.62%/96.33%/96.46%。支持均值在厘米尺度稳定，不代表概率已无限精确。
2. **主合成验证低 ESS：** sigma=0.005 m 时有 40 个 ESS<30 案例；全部另外用 10,000 粒子计算，平均交点最大变化约 0.113 m。诊断保存在 [particle_convergence.csv](../results/particle_convergence.csv)，没有替换冻结的 512 粒子主比较表。

40 个诊断案例中有 1 个真值先落地，没有可用的真值门平面坐标误差。不要强迫它参与坐标误差或覆盖率分母。

### 7.4 延长观测时间：有改善，也有校准问题

扩展人群为另外 400 条轨迹，每个时长仍只取 `T/2`、`T` 两个后续位置，初值相同；不是在原题观测基础上不断增加更多点。sigma 固定为 0.01 m。

| T / s | 共同坐标案例数 | M0 RMSE / m | M1 RMSE / m | M2 RMSE / m | M2 覆盖率 |
|---:|---:|---:|---:|---:|---:|
| 0.05 | 191 | 4.001 | 0.513 | 0.505 | 94.9% |
| 0.10 | 324 | 1.021 | 0.456 | 0.391 | 94.7% |
| 0.15 | 363 | 0.439 | 0.394 | 0.286 | 90.7% |
| 0.20 | 367 | 0.221 | 0.338 | 0.176 | 90.4% |

在 0.20 s 时，M0 确实优于遗漏旋转的 M1，但 RMSE 比较不能直接分离统计偏差和方差，不要写成“已测得偏差增加”。

**当前最值得继续的计算问题：** 扩展实验每案例只用 256 粒子。T=0.20 s 的最低 ESS 约 1.27，中位数约 26.13；400 个案例中有 217 个 ESS<30，覆盖率只有 90.4%。不能忽略这一失败的校准检查。

合理的下一步是增加有效采样或改进提议分布，并在同一批真值及噪声上比较区域覆盖率和点误差。现有证据只表明低 ESS 与覆盖不足同时出现，**还没有通过该扩展实验的粒子加密对照证明全部因果关系**。主实验那 40 个案例的加密不能代替扩展人群的对照。

如需继续这条线，先保存扩展实验各案例的初始参数、两次带噪观测、真值、编号和随机状态。当前主实验保存了专用观测 NPZ；扩展人群和带噪观测没有单独以同样方式完整导出。仅改粒子数会改变后续随机数流，不能把随之改变的人群当成严格配对改进。

不要由上述误差曲线推导“守门员只需观察多少秒就足够”的普遍生理结论；没有反应时间或人体运动模型支持。

### 9.4 只根据当前结果重新生成论文

先把需要保留的正文/引文修改同步到生成源，再运行：


不重跑蒙特卡洛，但会覆盖 article.json、TeX、Bib、公式和 PDF 等相关产物。

若只调用 `build_pdf()`，它会优先尝试 TeX 编译器；没有可用编译器时用 article.json 备用渲染。因此，**手工改了 TeX 后再调用它，不保证备用 PDF 也包含手工修改**。必须知道当前究竟使用哪条排版路径。

### 9.5 仅编译已经人工整理的 LaTeX

在已有合适 LaTeX 环境的机器上：

```powershell
Set-Location -LiteralPath 'D:\Codex\UPC\paper'
latexmk -pdf -interaction=nonstopmode -halt-on-error paper.tex
```

这是给下一位成员的操作方法，**不是本机已成功执行的证据**。需要检查 BibTeX、未定义引用、溢出版心和浮动体布局，实际查看 PDF。手工编译不会自动把旧的 build_status.json 改成真实新状态；应记录实际命令、日志和检查结论，不能只把 JSON 的布尔值改成 true。

当前 ReportLab PDF 的版式已查看全页缩略图及局部页面；LaTeX 版式还未验证。换渲染方式后必须重新查看，不可沿用备用版的版式检查结论。

### 9.6 改实验规模或采样算法时

不要只改一个 `particles` 或 `mc` 数字就宣布完成。还要检查：

- 收敛模块对原随机调用顺序的依赖；它会做实际内容一致性检查，不是哈希检查。
- 512/256 粒子、10,000 样本、噪声场景、时长及样本计数在报告中的固定说明。
- 共同案例、覆盖率、分类和失败分母。
- 原始记录是否足够重建同一批带噪观测。
- 随机数流变化是否使前后比较不再配对。
- 保存新旧设置和失败证据，重新生成关联图、表和正文。
